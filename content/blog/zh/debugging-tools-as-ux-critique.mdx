很多团队把调试工具当成上线前必须删掉的临时脚手架。但从桌面 AI 代理、硬件交互装置到策略原型一路做下来，真正帮我揪出「假体验」的，往往正是专门给设计评审造的离线调试台。

## 调试工具拆穿设计假象的四个真实瞬间

1. **[Lamplight Nook](/zh/projects/lamplight) 的零 API 事件回放器**：只靠真实 Claude SDK 现跑，超预算熔断与卡顿卡片几乎可遇不可求。我们在桌面壳内加装录制事件回放器，把罕见故障变成随时可拖动的评审标本。
2. **软硬协议帧单步重放**：在 [协议帧重放台](/zh/studio/replay) 里把 `15 ms` 红外毛刺拦截与句中拔线主动中止按毫秒拆开看，就能直观看懂为何固件门限直接保护了玩家信任。
3. **[实验室状态机](/zh/lab#fsm-explorer) 零死锁校验**：白板画箭头总是看上去闭环了，用广度优先图遍历一扫才会暴露哪条报错分支成了走不回待机态的死胡同。
4. **戳破绿灯构建下的静默降级**：收入 [演进档案馆](/zh/vault) 的早期比价与安全原型构建和单测全绿，真跑起来却静默退回无效匹配——逼出后来所有不确定态必须显性呈现的硬规矩。

## 可检查性本身就是一种设计诚实

当作品集把波形重放台、五态边界表和四重 [红队对抗答辩](/zh/ai) 一并交给评审时，对方不必靠猜去相信一张好看的静态截图，而是能直接把指针拖到最刁钻的故障帧上亲自验货。

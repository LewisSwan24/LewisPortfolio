失控的滚动动画对工程评审者来说是双重负担。触发重排的属性会拉高累积布局偏移（`CLS`）。忽略 `prefers-reduced-motion: reduce` 的遮罩动画，又会让开启减弱动效的用户卡在半透明的空白里。

在本站的 [实验室](/zh/lab) 与案例详情流中，GSAP 遵循三条克制边界：

## 1. 动态注册插件，仅动画合成层属性

所有动效只驱动 `x`、`y`、`scale` 与 `autoAlpha` 等合成层变换，绝不动 `width`、`height` 或 `top` 等布局属性。插件统一由 `src/lib/motion/gsap.ts` 中的 `getGsapWithScrollTrigger()` 按需异步加载并单次注册，让路由的 JS 保持精简。预算检查规定，单个路由块超过 `22 kB gz`，或者普通共享块超过 `70 kB gz`，构建就会失败。

## 2. 强制上下文清理与 `0ms` 即时落位

所有 React 组件内创建的动画均托管给 `gsap.context()` 与 `gsap.matchMedia()`，组件卸载时必须执行 `.revert()` 彻底回收监听。一旦检测到 `prefers-reduced-motion: reduce`，所有过渡瞬间按 `0ms` 结算完成态，确保正文内容永远立即可读。

## 3. 动效与 3D 永远退居核心文本之后

WebGL 未启用时，首页的 3D/矢量标尺会在 `0ms` 内静态呈现在 SVG 轴上。Playwright 测试（`e2e/v42-three-and-matrix.spec.ts` 与 `e2e/v45-security-and-cwv.spec.ts`）持续守卫主路由零控制台报错，并把 `CLS` 控制在 `0.05` 以内。你可以前往 [实验室](/zh/lab) 亲自调节并校验动效曲线参数。

Hiring teams now run candidate repositories and portfolios through MCP clients directly inside editors. Treating that traffic like casual HTML scraping invites silent leaks: unlisted coursework fragments surface in generic queries, or raw job descriptions echo secrets in plain text.

## Enforcing contract boundaries on the server

In this site, `/api/mcp` ships strictly read-only Zod `.strict()` handlers alongside `/.well-known/mcp.json` and `/llms-full.txt`:

1. **Five scoped tools, zero writes**: Queries run against static listed flagships, pattern specs, protocol replay frames, and archive vault lessons without database side effects.
2. **Hard unlisted isolation**: Search and tradeoff tools physically filter to `LISTED_PROJECT_SLUGS`; archival studies appear only inside the explicit `audit_vault_lineage` tool.
3. **Secret scrubbing before scoring**: Input sanitizers strip emails, phone tokens, `Bearer`, `sk-`, `ghp_`, and `AIza` keys prior to local BM25 ranking inside [AI Lab](/ai).

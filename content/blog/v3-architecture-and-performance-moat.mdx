A portfolio for interaction and design-engineering roles should feel effortless to read and hold up to basic web hygiene. During the V3 refactor of this site, I audited what actually reached the reader's browser and every place where case-study facts drifted apart across files.

The goal was never a visual overhaul—the warm-paper typography and editorial pacing already fit the work. The real goal was eliminating duplicated data, keeping initial page loads responsive, and catching accessibility or broken-link slips before they reach production.

## Moving case studies out of client JSON bundles

Earlier versions stored narrative case-study copy inside global translation dictionaries (`en.json` and `zh.json`). Because `NextIntlClientProvider` serialized the whole object into HTML, visiting the home page meant downloading bilingual essays for ten projects just to render the top bar.

Consolidating all case records into typed `src/data/cases/*.ts` modules validated with **Zod** reversed that weight right away: client bundles now receive only interactive interface labels (`nav`, `contact`, `resume`, `search`), cutting translation payloads to a fraction of their former size while keeping project slugs, media paths, and review schedules checked automatically.

## Stopping client boundary creep on the Work Index

Even after slimming dictionaries, build inspection flagged `/projects` as noticeably heavier than other routes because `WorkIndex` sat behind a `"use client"` boundary—pulling interactive thumbnails, summaries, and helpers into client JavaScript just to power a filter bar.

Lifting those presentational blocks back into the Server Component (`app/[locale]/projects/page.tsx`) and passing rendered slots left only the lightweight tab toggle on the client, dropping the `/projects` route script to roughly **1.25 kB** so automated CI budget checks can keep interaction pages crisp. <AnchorNote term="RSC slot pattern" label="Engineering note" note="Passing pre-rendered server ReactNode trees as props into a small client wrapper keeps heavy SVG/media helpers off the browser bundle." />

## Lighter assets, calmer motion, and accessibility checks

Three practical habits closed the loop:

1. **Media discipline (`pnpm media:check`)**: Compressing screenshots and looping clips kept the entire visual archive light and snappy without degrading type clarity.
2. **Restrained GSAP motion**: Centralizing subtle reveals with `useGsapContext` cleanup and `prefers-reduced-motion` support makes transitions settle immediately for visitors who prefer reduced motion.
3. **Multi-viewport accessibility scans**: Automated `@axe-core/playwright` checks cover Desktop Light, Desktop Dark (`#141413`), and Mobile viewports together, ensuring contrast and focus rings stay intact across themes.

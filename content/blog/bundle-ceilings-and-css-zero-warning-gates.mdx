Performance budgets die slowly: a helper imports a heavy server barrel into one client island, or an experimental CSS at-rule triggers compiler warnings that everyone ignores until production breaks.

## Turning bundle budgets into failing build assertions

On [Lab Section 08](/lab#bundle-observatory), telemetry comes from the build output rather than hand-typed numbers:

1. **Isolated shared lazy chunks**: WebGL runs only inside a `dynamic(ssr: false)` chunk. `pnpm budget:check` fails the build if that lazy 3D chunk passes `160 kB gz` or any app route chunk passes `22 kB gz`. The build manifest generated on 24 November 2026 recorded `82.4 kB gz` and `15.3 kB gz` respectively.
2. **LightningCSS zero-warning guard**: `pnpm css:check` rejects unsupported experimental `@container anchored(...)` rules before compilation begins.
3. **Manifest snapshot discipline**: `pnpm telemetry:build` extracts real gzipped `.next/static` measurements alongside proof metadata review dates.

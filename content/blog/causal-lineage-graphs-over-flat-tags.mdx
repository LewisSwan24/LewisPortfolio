Traditional portfolios flatten iteration into disconnected filter chips. A visitor sees a finished project without seeing which earlier attempts it relates to.

## What the graph shows

On [/studio/graph](/studio/graph), nodes sit in typed tiers: archived studies, listed case studies, interaction patterns and essay clusters. The links between them are my own reading of how the projects relate. They are not recorded causes, so a link should not be read as proof that one project produced another's rules.

- **Gap overlay**: a filter highlights claims that still have no field evidence, instead of hiding them.
- **Keyboard and screen-reader parity**: next to the drawn links sits an HTML adjacency table with arrow-key navigation.
- **Layout on the server**: node positions are computed on the server rather than in the browser.

Watch anyone work with an IDE, a browser, and a background coding agent simultaneously. Focus jumps are inevitable—and humans clear modal interruptions faster than they read them. That mismatch creates **Enter-key fatigue**: the moment a confirmation dialog defaults keyboard focus onto `Approve`, an unintended keystroke commits an irreversible file write or shell command.

## Designing against muscle-memory rubber-stamping

In [Lamplight Nook](/projects/lamplight), we paired visual calm with an uncompromising keyboard default across every risk confirmation card:

1. **Default focus stays anchored on `'Not now'`**: Pressing `Enter` or `Space` reflexively defers or cancels the risky action rather than executing it. Approving requires an intentional `Tab` move or deliberate pointer click.
2. **Copy-only file isolation behind the scenes**: Even before an operator approves anything, lent reference files live inside working copies alongside a hard per-run spending ceiling.
3. **Honest naming over dark patterns**: `'Not now'` avoids shaming language (`"No, keep my workflow slow"`) and leaves prior subtasks intact so deferral carries zero penalty.
